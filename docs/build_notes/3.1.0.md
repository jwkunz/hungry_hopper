# 3.1.0 (Android app)

- Android app (Gradle project in `Android/`): a full-screen landscape WebView that bundles the web build as `assets/index.html`.
- One `VERSION` file drives the web package version and the Android `versionName` / `versionCode`; `scripts/version.mjs` keeps them in step.
- New `ci.yml` builds the tests, the single HTML file and the debug APK; a `v*` tag publishes a release.
- README restructured; gameplay guide moved to `docs/gameplay.md` and the changelog to `docs/build_notes/`.
